# Example: Overleaf Trial

## Spend Summary

- Spend: Overleaf paid plan or trial
- Amount: Trial or plan-dependent
- Billing period: Trial window or monthly
- Payment or renewal date: End of trial or next renewal
- Tool, service, person, or infrastructure: Collaborative LaTeX writing environment

## Why Pay Now?

The paid or trial window is being used to finish a paper. The spend is justified only if it converts writing momentum into a durable artifact.

If the user waits, the paper may stall or collaboration may slow down. The value comes from finishing, exporting, and publishing the work, not from keeping the subscription indefinitely.

## Durable Asset Target

The spend should create:

- finished paper draft
- GitHub repository artifact
- Zenodo artifact
- exported PDF
- reproducible source files

## KPI Window

- Start date: Today
- End date: 7 days from today
- KPI: Complete and export the paper artifact
- Minimum acceptable result: Paper draft exported, source backed up, and artifact path chosen
- Evidence required: PDF export, GitHub repository, Zenodo draft, or archived source bundle

## Stop-Loss Line

- Stop-loss date: End of trial or before paid renewal
- Stop-loss condition: No paper artifact is exported or archived
- Next billing or renewal date: Trial end or next Overleaf billing date
- Cancellation owner: User

## Rescale Option

- Use the trial only
- Export source files before renewal
- Continue in local LaTeX tooling
- Collaborate through GitHub or another reversible workflow

## Decision

`GO`

## Decision Rationale

This is a time-boxed GO because the spend directly converts into a durable asset: paper, GitHub artifact, or Zenodo artifact. The subscription is justified by artifact completion, not by general convenience.

## Next Safe Action

Schedule the export and archive step before the trial or billing window ends.
