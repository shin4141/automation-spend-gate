# Example: Claude Pro / Codex

## Spend Summary

- Spend: Claude Pro, Codex, or similar AI coding assistant
- Amount: Plan-dependent
- Billing period: Monthly or usage-based
- Payment or renewal date: Before plan renewal or credit purchase
- Tool, service, person, or infrastructure: AI assistant for prototypes, PRs, demos, analysis, and automation work

## Why Pay Now?

The spend is justified only if it accelerates a concrete build or automation outcome. General usefulness is not enough.

If the user waits, they may still be able to use a free tier, existing credits, a smaller model, or manual work for the next 7 days.

## Durable Asset Target

The spend should create at least one durable asset:

- working prototype
- merged PR
- published demo
- repeatable automation
- documented workflow
- measurable time savings from a recurring task

## KPI Window

- Start date: Today
- End date: 7 days from today
- KPI: Produce one prototype, merged PR, published demo, repeatable automation, or measurable time saved
- Minimum acceptable result: One concrete artifact or a documented time-saving result
- Evidence required: PR link, demo link, repository commit, workflow doc, or time-saved note

## Stop-Loss Line

- Stop-loss date: 7 days from payment or before next renewal
- Stop-loss condition: No prototype, merged PR, published demo, repeatable automation, or measurable time saved appears
- Next billing or renewal date: Next plan renewal or credit purchase date
- Cancellation owner: User

## Rescale Option

- Use a free tier
- Use existing credits first
- Downgrade to a lower plan
- Pause the subscription between build windows
- Use a cheaper model for routine tasks
- Batch work into a shorter paid window

## Decision

`GO` only with a 7-day KPI

## Decision Rationale

Claude Pro, Codex, or similar tools can be high-leverage, but the spend must produce visible option value quickly. If no prototype, merged PR, published demo, or measurable time saved appears, downgrade or pause.

## Next Safe Action

Choose the one artifact that must exist in 7 days and write the stop-loss reminder before paying or renewing.
