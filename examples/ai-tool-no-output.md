# Example: AI Tool Subscription With No Output

## Spend Summary

- Spend: AI tool subscription
- Amount: Monthly plan
- Billing period: Monthly
- Payment or renewal date: Next renewal date
- Tool, service, person, or infrastructure: AI assistant or automation tool

## Renewal Gate

Before this renews, what evidence justifies paying again?

There has been no meaningful output in 14 days. No prototype, merged PR, published demo, reusable workflow, or measurable time saved has appeared.

## Profit Gradient

Usage alone does not justify renewal. The tool needs to create future profit, time saved, reusable assets, or reduced failure rate. In this case, the gradient is not visible.

## No-Use Cut Rule

- No meaningful use in the last N days: Yes, 14 days
- No concrete next-7-day use: Yes
- Low rejoin cost: Yes, the subscription can be restarted later
- Low data/operation risk: Yes, no live operation depends on it

## Decision

`STOP`

## Rejoin Condition

Rejoin when there is a named 7-day build target, such as a prototype, merged PR, published demo, or automation workflow that cannot be completed efficiently without the tool.

## Protected Margin

Protected margin is the avoided subscription spend until a concrete build window returns.

## Next Safe Action

Cancel before renewal and write down the next build target that would justify rejoining.
